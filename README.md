# Smart Pet Tracker (ระบบเฝ้าระวังและแจ้งเตือนพฤติกรรมสัตว์เลี้ยงด้วย IoT)

โปรเจกต์นี้คือระบบปลอกคออัจฉริยะที่ใช้ไมโครคอนโทรลเลอร์ ESP32 ในการติดตามและเฝ้าระวังพฤติกรรมสัตว์เลี้ยง โดยรองรับทั้งการส่งข้อมูลผ่าน Wi-Fi โดยตรง และการสื่อสารระยะไกลผ่านคลื่นวิทยุ (LoRa Gateway)

## ✨ คุณสมบัติเด่น (Features)
* **ติดตามตำแหน่ง (GPS Tracking):** ทำการอ่านพิกัดดาวเทียมเพื่อระบุตำแหน่งสัตว์เลี้ยง พร้อมสร้างลิงก์แผนที่ Google Maps แบบอัปเดตอัตโนมัติ
* **ระบบรั้วเสมือน (Geofencing):** รองรับการตั้งค่าพิกัดจุดศูนย์กลางหรือพิกัดบ้าน (Home) และระบบจะแจ้งเตือนเมื่อสัตว์เลี้ยงออกนอกระยะรัศมีที่กำหนดไว้
* **ตรวจจับพฤติกรรม (Behavior Monitoring):** ใช้เซนเซอร์ MPU6050 ในการวัดค่าความเร่งและแรงกระแทก เพื่อประเมินสถานะการวิ่งตื่นตระหนก หรือการล้มคว่ำบาดเจ็บ
* **โหมดพลังงานแบบปรับตัว (Adaptive Operation Mode):** ระบบจะทำงานในโหมดปกติโดยสตรีมข้อมูลทุกๆ 15 วินาทีเพื่อประหยัดพลังงาน และจะเร่งความถี่การส่งเป็นทุกๆ 2 วินาทีโดยอัตโนมัติเมื่อเกิดเหตุฉุกเฉิน
* **มาตรวัดแบตเตอรี่เสมือน (Virtual Fuel Gauge):** ทำการประเมินเปอร์เซ็นต์แบตเตอรี่และคำนวณระยะเวลาการใช้งานที่คงเหลือ จากอัตราการดึงกระแสไฟฟ้าจริง
* **การแจ้งเตือน (Real-time Alerts):** แสดงผลสถานะทั้งหมดผ่านแดชบอร์ดแอปพลิเคชัน Blynk และทำการส่งข้อความแจ้งเตือนภัยผ่านทาง LINE Notify

## 🛠️ ฮาร์ดแวร์และเทคโนโลยี (Hardware & Tech Stack)
* บอร์ดไมโครคอนโทรลเลอร์ ESP32
* โมดูลรับสัญญาณ GPS พร้อมไลบรารี TinyGPS++
* เซนเซอร์วัดความเร่ง MPU6050 (เชื่อมต่อผ่านโปรโตคอล I2C)
* โมดูลส่งสัญญาณวิทยุ LoRa (ใช้งานร่วมกับขา M0, M1, AUX)
* แพลตฟอร์ม Blynk IoT และ API ของ LINE Notify

## 📁 โครงสร้างของระบบ (System Architecture)
ซอร์สโค้ดในโปรเจกต์นี้แบ่งการทำงานออกเป็น 2 รูปแบบหลัก:
1. **Wi-Fi Direct Model:** โค้ดสำหรับปลอกคอเดี่ยวที่ทำการเชื่อมต่อเครือข่าย Wi-Fi และส่งข้อมูลขึ้นคลาวด์โดยตรง
2. **LoRa Gateway Model:** ระบบที่แบ่งการทำงานเป็น "โหนดส่งสัญญาณ (ปลอกคอ)" และ "โหนดรับสัญญาณ (สถานีฐาน)" ที่ทำหน้าที่รับแพ็กเกจข้อมูลผ่านคลื่นวิทยุแล้วส่งต่อขึ้นอินเทอร์เน็ต
